# Admin screen (prototype)

หน้าผู้ดูแลระบบ: ตั้งนโยบายระบบ (แสดงชื่อผู้ส่ง ระยะเวลาล็อก ความถี่ซิงก์ เกณฑ์สัดส่วนรายการนำเข้าที่หาย) จัดการบัญชีและบทบาท
กำหนด/ยุติ/โอนความสัมพันธ์ครู-ผู้เรียน และดูประวัติการเปลี่ยนแปลง ทุกการกระทำเรียก Backend (callable) หน้านี้ไม่แตะ Firestore ตรง
บัญชีต้องมี `users/{uid}` ที่ `status: "active"` และบทบาท `admin`

ทดสอบกับ emulator: ทำตามขั้นตอนใน `../review-queue/README.md` ข้อ 1-2 (เปิด emulator และ seed) แล้วเปิดเว็บจากโฟลเดอร์ `web`:

```bash
npx serve web
```

เปิด `http://localhost:3000/login/#emulator` แล้ว login ด้วย `reviewer2@example.test` (ระบบพาไป `/admin/` เอง ถ้าเปิด `/admin/#emulator` ตอนยังไม่ล็อกอินจะเด้งไป login) (บัญชี seed ที่เป็น admin) โหมดโปรเจกต์จริงใช้ `../review-queue/firebase-config.js` ร่วมกัน
ข้อควรระวัง: เป็น prototype ใช้กับข้อมูลตัวอย่างเท่านั้น และยังไม่มีรายการบัญชีให้เลือก (ต้องกรอก uid เอง)

ส่วนกำหนดครู-ผู้เรียนมีตาราง "ความสัมพันธ์ที่มีอยู่" (เรียก `listAssignments`) แสดงทั้งสถานะใช้งานและยุติแล้ว โหลดตอนเข้าหน้า หลังกำหนด/ยุติ/โอน และกด "โหลดใหม่" ปุ่ม "ยุติความสัมพันธ์" มีกล่องยืนยันก่อน
