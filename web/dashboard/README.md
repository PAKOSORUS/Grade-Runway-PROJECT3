# Learner dashboard / advisor view (prototype)

หน้าสถานการณ์การเรียน: ผู้เรียนเห็นภาพรวม 4 ตัวแปร (เกรด เข้าเรียน ส่งงาน แนวโน้ม) เหตุผลที่เข้าเงื่อนไขเสี่ยง คำแนะนำ และประวัติการแจ้งเตือน
ครูที่ปรึกษาเลือกดูผู้เรียนในความดูแลได้ (อ่านอย่างเดียว) ถ้ายังไม่เคยซิงก์สำเร็จจะแสดงป้าย "รอข้อมูล" และไม่แสดงผลประเมินใด ถ้าซิงก์ล่าสุดล้มเหลวจะแสดงป้าย "ข้อมูลไม่ทันสมัย"
ทุกการกระทำเรียก Backend (`getLearnerSituation`, `listMyLearners`) หน้านี้ไม่แตะ Firestore ตรง

ทดสอบกับ emulator: ทำตามขั้นตอนใน `../review-queue/README.md` ข้อ 1-2 (seed มีข้อมูลซิงก์ ผลการเรียน และกฎ threshold แล้ว) แล้วเปิดเว็บจากโฟลเดอร์ `web`:

```bash
npx serve web
```

1. เปิด `http://localhost:3000/login/#emulator` login ด้วย `reviewer2@example.test` กด "ประเมินความเสี่ยงตอนนี้" (ยังไม่มีงานซิงก์อัตโนมัติ)
2. ออกจากระบบ แล้ว login ที่ `http://localhost:3000/login/#emulator` ด้วย `student1@example.test` (ผู้เรียนที่เสี่ยง) หรือ `advisor1@example.test` (ครูของ student1)

บัญชีทดสอบใช้รหัสผ่านที่ seed พิมพ์ไว้ ใช้ได้เฉพาะใน emulator ข้อควรระวัง: เป็น prototype ใช้กับข้อมูลตัวอย่างเท่านั้น
