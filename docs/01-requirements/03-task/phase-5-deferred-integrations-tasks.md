# Phase 5: งานที่รอการตัดสินใจเรื่องการตั้งเวลา อีเมล และ AI

อ้างอิง [[../02-plan/release-plan]] | [[../backlog|Backlog]] | [[../../02-design/feature-list|Feature List]] | ต้องเสร็จ phase 2, 3 และ 4 ก่อน

หมายเหตุ: การตั้งเวลา อีเมล และ AI ยังไม่ได้ตัดสินใจใน [[../../02-design/02-technical/technology-stack]] ต้องตัดสินก่อนเริ่ม task ที่เกี่ยวข้อง

| รหัส task | ชื่องาน | FR/NFR | หมายเหตุ dependency |
|-----------|---------|--------|---------------------|
| T-5-01 | ซิงก์ข้อมูลจากระบบเดิมอัตโนมัติตามรอบที่ Admin กำหนด (ความถี่ยังไม่กำหนด) | NFR-03, FR-01 | รอตัดสินใจกลไกตั้งเวลา; T-2-02 |
| T-5-02 | แสดงเวลาซิงก์ล่าสุดเพื่อให้ผู้ใช้ประเมินความทันสมัยของข้อมูล | NFR-03 | T-5-01 |
| T-5-03 | ปลดล็อกข้อความที่ค้างตามรอบเวลาโดยไม่ต้องรอการเข้าถึงข้อความ (ถ้า phase 3 ใช้ทางเลือกชั่วคราว) | FR-21 | รอตัดสินใจกลไกตั้งเวลา; T-3-10 |
| T-5-04 | ส่งการแจ้งเตือนความเสี่ยงทางอีเมลถึงผู้เรียนพร้อมเหตุผล | FR-04, NFR-02 | รอตัดสินใจช่องทางอีเมล; T-4-05, T-4-06 |
| T-5-05 | เก็บประวัติการแจ้งเตือนและคำแนะนำย้อนหลัง | FR-09 | T-4-05, T-4-07 |
| T-5-06 | ผู้เรียนและครู/อาจารย์ที่ปรึกษาเปิดดูประวัติย้อนหลังตามสิทธิ์การมองเห็น | FR-09, NFR-01 | T-5-05 |
| T-5-07 | AI เสนอผลวิเคราะห์เชิงลบ/ไม่เชิงลบให้ผู้ตรวจ ผู้ตรวจยืนยันขั้นสุดท้ายเอง | FR-17 | รอตัดสินใจเรื่อง AI; T-3-07 |
| T-5-08 | บันทึกใน audit trail ว่าผลสุดท้ายมาจากผู้ตรวจ และผลที่ AI เสนอ (ถ้ามี) | FR-17, NFR-05 | T-5-07 |
