# Phase 3: แชทแนะนำที่ผ่านการตรวจ

อ้างอิง [[../02-plan/release-plan]] | [[../backlog|Backlog]] | [[../../02-design/feature-list|Feature List]] | ต้องเสร็จ phase 1 และ 2 ก่อน

หลักการ: การเปลี่ยนสถานะข้อความทุกอย่าง (ล็อก ตัดสิน ปลดล็อก ส่งใหม่) ตรวจล็อกและบันทึก audit ในหน่วยการทำงานเดียว ผู้ใช้ปลายทางเปลี่ยนสถานะเองโดยตรงไม่ได้

| รหัส task | ชื่องาน | FR/NFR | หมายเหตุ dependency |
|-----------|---------|--------|---------------------|
| T-3-01 | นักศึกษาส่งข้อความแนะนำเข้าห้องรวมได้ ข้อความเข้าสถานะรออนุมัติ | FR-10, FR-11, FR-20 | phase 1 |
| T-3-02 | ตรวจสิทธิ์ผู้ส่งตามเกณฑ์ผู้ผ่านเกณฑ์ ณ เวลาส่ง ผู้ไม่ผ่านส่งไม่ได้ | FR-16 | T-3-01, T-2-11 |
| T-3-03 | ข้อความที่ยังไม่อนุมัติหรือถูกปฏิเสธไม่ปรากฏต่อผู้รับไม่ว่าทางใด | FR-11, NFR-04 | T-3-01 |
| T-3-04 | ห้องรวมแสดงเฉพาะข้อความที่อนุมัติแล้ว ให้นักศึกษาทุกคนเห็น | FR-20, NFR-04 | T-3-03 |
| T-3-05 | อาจารย์/Admin เห็นคิวข้อความรออนุมัติ | FR-13 | T-3-01 |
| T-3-06 | ผู้ตรวจล็อกข้อความที่จะตรวจ ผู้ตรวจคนอื่นตัดสินข้อความนั้นซ้ำไม่ได้ | FR-18 | T-3-05 |
| T-3-07 | ผู้ตรวจระบุเชิงลบ/ไม่เชิงลบก่อนอนุมัติ และเลือกอนุมัติหรือปฏิเสธเองแม้เป็นเชิงลบ (ไม่ปฏิเสธอัตโนมัติ) | FR-12, FR-13, FR-14 | T-3-06 |
| T-3-08 | ปฏิเสธต้องกรอกเหตุผล และผู้ส่งได้รับแจ้งพร้อมเหตุผลในแอป | FR-15 | T-3-07 |
| T-3-09 | คำตัดสินที่กดโดยไม่ถือล็อกที่ใช้ได้ (หมดอายุ/ปลดด้วยมือ/ผู้อื่นล็อกต่อ) ไม่ถูกบันทึก แจ้งผู้ตรวจ ข้อความอยู่ในคิว | FR-24, NFR-04, NFR-05 | T-3-06, T-3-07 |
| T-3-10 | ล็อกที่ค้างถูกปลดอัตโนมัติเมื่อครบเวลา (ค่าตั้งได้) ข้อความกลับเข้าคิวและไม่ถือเป็นการตัดสิน | FR-21 | T-3-06 หมายเหตุ: การเรียกใช้อัตโนมัติตามรอบอาจต้องรอ phase 5 ถ้ายังไม่มีกลไกตั้งเวลา ให้ตรวจเมื่อมีการเข้าถึงข้อความแทน |
| T-3-11 | อาจารย์/Admin ปลดล็อกข้อความที่ผู้ตรวจค้างด้วยมือ | FR-21 | T-3-06 |
| T-3-12 | บันทึกประวัติการตรวจ: ใครตรวจ ผลตัดสิน เชิงลบ/ไม่เชิงลบ เหตุผล ไม่แก้ย้อนหลังได้ | NFR-05 | T-3-07 |
| T-3-13 | ข้อความที่ถูกปฏิเสธปิดถาวรและแก้ไม่ได้ ผู้ส่งสร้างข้อความใหม่ได้ครั้งละหนึ่ง (ห้ามส่งใหม่ถ้าข้อความใหม่ที่โยงกันรออนุมัติหรืออนุมัติแล้ว) | FR-22 | T-3-08 |
| T-3-14 | บันทึกความสัมพันธ์ข้อความเดิม-ใหม่ใน audit trail | FR-22, NFR-05 | T-3-12, T-3-13 |
| T-3-15 | ตั้งนโยบายการแสดงชื่อผู้ส่งตามที่ตัดสินใจแล้ว และบันทึกประวัติการเปลี่ยนนโยบาย | NFR-06, NFR-07 | T-3-04 หมายเหตุ: นโยบายแสดงชื่อยังไม่กำหนด ต้องรอผู้ใช้ตัดสินก่อนทำ |
