# Backlog ฉบับเดิม (นำเข้าจากโปรเจกต์เดิม — เก็บเพื่ออ้างอิง)

> ไม่ใช่ backlog ที่ใช้งานอยู่ แหล่งอ้างอิงปัจจุบันคือ [[../01-requirements/backlog|Backlog]] ซึ่งจัดเป็นระดับ FR/NFR (สูง/กลาง/ต่ำ) ส่วนไฟล์นี้เป็นระดับ work item (รหัส `BL-…`) ที่รวมหลาย FR ไว้ในแถวเดียว เก็บไว้เพื่อให้ย้อนดูการจัดกลุ่มงานเดิมได้
