## Firestore rules ตามบทบาท
- ผู้ใช้ตัดสินใจ: ให้เฉพาะ lecturer/admin อ่าน `chatMessages` ตรงผ่าน rules (อ่านอย่างเดียว) ส่วนอื่นผ่าน Backend
- แก้ `firebase/firestore.rules`: ลบกฎเปิดอ่านชั่วคราว (ขัด NFR-04/06) แทนด้วยกฎ `isReviewer()` อ่านบทบาทจาก `users/{auth uid}` ต้อง `status == active`; collection อื่นและการเขียนปฏิเสธทั้งหมด
- อัปเดตแถว Security Rules ใน [[../02-design/02-technical/technology-stack]]
- ข้อสมมติ: id เอกสาร `users` ต้องเท่ากับ Auth uid (ผู้ใช้ตัวอย่างไม่ตรง)
- ค้าง: หน้า `web/review-queue/` ต้องเพิ่ม login ก่อนใช้กับ rules นี้ (ถ้าวาง rules ตอนนี้หน้าจะอ่านไม่ได้); ผู้ใช้วาง rules ใน Console เอง; ยังไม่ได้ทดสอบ rules (ไม่ได้ใช้ emulator)
- คำถามที่ถามผู้ใช้: 1 ข้อ | ไม่มี NEEDS_NEW_REQUIREMENT
