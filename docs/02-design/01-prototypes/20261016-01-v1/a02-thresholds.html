ตั้งค่า threshold ความเสี่ยง

ค่าตัวอย่าง spec ยังไม่กำหนดค่า threshold จริง ตัวเลขด้านล่างเป็นตัวอย่างเท่านั้น
บันทึกแล้ว
การประเมินรอบถัดไปใช้ค่าใหม่ (FR-03) การแจ้งเตือนที่ส่งไปแล้วไม่เปลี่ยน

กฎของแต่ละตัวแปร (FR-08)

ช่วงที่ใช้ได้ 0.00 - 4.00กรอกตัวเลขระหว่าง 0.00 ถึง 4.00
ช่วงที่ใช้ได้ 0 - 100กรอกตัวเลขระหว่าง 0 ถึง 100
ช่วงที่ใช้ได้ 0 - 100กรอกตัวเลขระหว่าง 0 ถึง 100
ช่วงที่ใช้ได้ 1 - 10กรอกจำนวนเต็มระหว่าง 1 ถึง 10

ตัวอย่าง การแปลงจำนวนเงื่อนไขเป็นระดับ (prototype สมมติ: 1 เงื่อนไข = เฝ้าระวัง, ตั้งแต่ 2 = เสี่ยงสูง) spec ยังไม่กำหนด

ใครเห็นอะไร (NFR-01)

เฉพาะผู้ดูแลระบบเข้าหน้านี้ได้ ผู้เรียนและครูไม่เห็นเมนูนี้
