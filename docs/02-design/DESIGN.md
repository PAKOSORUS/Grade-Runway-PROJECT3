# DESIGN — Design System ของ Grade Runway

> **สถานะ: ยืนยันแล้ว (2026-10-16)** — ผู้ใช้ยืนยันร่างตามที่เสนอทุกข้อ รวมถึงค่าที่เป็น (ประมาณ) และ (เสนอ) ใช้เป็นแหล่งอ้างอิงสำหรับ prototype ได้
> ค่าที่ทำเครื่องหมาย **(ประมาณ)** อ่านจากภาพหน้าจอ ไม่ได้วัดพิกเซลจริง หากภายหลังมีค่าจริง (เช่น hex จากต้นฉบับ) ให้แก้ที่ไฟล์นี้ก่อน แล้วค่อยสะท้อนไป prototype
> ค่าที่ทำเครื่องหมาย **(เสนอ)** ไม่มีในภาพต้นแบบ เป็นข้อเสนอของผู้ร่าง

แรงบันดาลใจ: โทนและโครงสร้างของระบบทะเบียนที่ผู้ใช้แนบภาพมา (ภาพที่ 1 หน้า Monthly Activities, ภาพที่ 2 หน้า Login History) **ใช้เฉพาะโทนสีและโครงสร้างเท่านั้น ไม่นำโลโก้ ตราสัญลักษณ์ หรือชื่อของมหาวิทยาลัยมาใช้** Grade Runway ต้องมีโลโก้/ชื่อของตัวเอง

เอกสารที่เกี่ยวข้อง: [[feature-list]], [[user-journey]]

## 1. หลักการ
- โครงสร้างแบบระบบสารสนเทศมหาวิทยาลัย: แถบหัวบน + เมนูข้างซ้าย + พื้นที่เนื้อหาเป็นการ์ดขาวบนพื้นเทาอมม่วงอ่อน
- สีแบรนด์เป็นโทนมารูน/ดินแดง ใช้กับหัวตาราง ปุ่มหลัก หน้าที่ถูกเลือก เท่านั้น ส่วนที่เหลือเป็นขาว/เทา เพื่อให้อ่านง่าย
- สองภาษา ไทย (TH) และอังกฤษ (EN) สลับได้จากแถบหัว ทุกหน้าต้องรองรับความยาวข้อความที่ต่างกันสองภาษา
- สถานะความเสี่ยงต้องไม่พึ่ง "สีอย่างเดียว" (ดูข้อ 9)

## 2. สี (Color tokens)

### 2.1 สีหลักและสีรอง
| Token | Hex | ใช้กับ | หมายเหตุ |
|-------|-----|--------|----------|
| `--color-brand` | `#9B4033` | หัวตาราง, ปุ่มหลัก, หน้า pagination ที่เลือก, ลิงก์เมนูที่ active | (ประมาณ) อ่านจากหัวตาราง |
| `--color-brand-dark` | `#7F3026` | ปุ่มหลักตอน hover/pressed, เส้นเน้น | (เสนอ) เข้มกว่า brand ~15% |
| `--color-brand-tint` | `#F5E4DA` | พื้นวงกลมหลังไอคอนเมนูที่ active, พื้นแถวที่เลือก | (ประมาณ) สีครีมอมส้มอ่อนในภาพ |
| `--color-accent-text` | `#9B4033` | รหัสผู้ใช้ในแถบหัว, ลิงก์ | ใช้ค่าเดียวกับ brand |

### 2.2 พื้นหลังและเส้น
| Token | Hex | ใช้กับ |
|-------|-----|--------|
| `--color-bg-page` | `#F8F8FC` | พื้นหลังหน้า (เทาอมม่วงอ่อนมาก) (ประมาณ) |
| `--color-bg-surface` | `#FFFFFF` | การ์ด, แถบหัว, เมนูข้าง, ช่องกรอก |
| `--color-bg-row-stripe` | `#FAF7F4` | แถวข้อมูลในตาราง (อมครีมจางๆ) (ประมาณ) |
| `--color-border` | `#E3E3E8` | เส้นแบ่งแถว, กรอบช่องกรอก (ประมาณ) |
| `--color-shadow` | `rgba(0,0,0,0.08)` | เงาการ์ด `0 1px 4px` (ประมาณ) |

### 2.3 ข้อความ
| Token | Hex | ใช้กับ |
|-------|-----|--------|
| `--color-text` | `#1F1F1F` | ข้อความหลัก, หัวเรื่องหน้า (ประมาณ) |
| `--color-text-muted` | `#6B6B76` | ข้อความรอง, footer, label จาง (ประมาณ) |
| `--color-text-on-brand` | `#FFFFFF` | ข้อความบนพื้นสีแบรนด์ |

### 2.4 สีสถานะ (เสนอ — ไม่มีในต้นแบบ)
ระบบเตือนผลการเรียนต้องมีสามระดับ โดยเลือกให้ต่างจากสีแบรนด์ซึ่งเป็นแดง-ดินอยู่แล้ว เพื่อไม่ให้ "แบรนด์" กับ "อันตราย" สับสนกัน

| ระดับ | Token | พื้น (bg) | ขอบ/ไอคอน | ข้อความ | ความหมาย |
|-------|-------|-----------|-----------|---------|----------|
| ปกติ | `--status-ok` | `#E6F4EA` | `#2E7D4F` | `#1E5C38` | ผลการเรียนอยู่ในเกณฑ์ |
| เตือน | `--status-warn` | `#FFF4DB` | `#C98A00` | `#7A5200` | เข้าเงื่อนไขเสี่ยง ควรติดตาม |
| อันตราย | `--status-danger` | `#FDE7E7` | `#C62828` | `#8E1B1B` | เสี่ยงสูง ต้องดำเนินการ |

- ใช้สีน้ำเงินกลาง `#1F5FA8` เป็น `--status-info` (เสนอ) สำหรับข้อความแจ้งทั่วไป เช่น ป้าย "ข้อมูลไม่ทันสมัย" (FR-19) หรือ "รอข้อมูลซิงก์" (FR-23) เพราะไม่ใช่ระดับความเสี่ยง
- `--status-danger` (`#C62828`) สว่างและอมแดงสดกว่า brand (`#9B4033`) ตั้งใจให้แยกกันได้ แต่ **ยังใกล้กันพอที่ต้องมีไอคอนและข้อความกำกับเสมอ** (ข้อ 9)
- ความคมชัดตัวอักษร: ขาวบน `#9B4033` ประมาณ 6.6:1 ผ่าน AA; คู่สีสถานะข้างบนควรตรวจด้วยเครื่องมือจริงก่อน build (ยังไม่ได้วัด)

## 3. ตัวอักษร (Typography)
ภาพต้นแบบใช้ฟอนต์ sans-serif เรขาคณิต ตัวกลม เส้นสม่ำเสมอ ลักษณะใกล้ Raleway/Quicksand ระบุชื่อแน่ชัดจากภาพไม่ได้ **(ประมาณ)**

| รายการ | ค่า |
|--------|-----|
| ฟอนต์หลัก (เสนอ) | `"Noto Sans Thai", "Raleway", system-ui, sans-serif` — Noto Sans Thai รองรับไทยครบ ใช้ Google Fonts ได้ |
| ฟอนต์ตัวเลข/อังกฤษ | ใช้ชุดเดียวกัน เพื่อไม่ให้ไทย-อังกฤษดูแยกกัน |
| น้ำหนัก | 400 (ปกติ), 500 (เมนู/หัวข้อการ์ด), 600 (หัวตาราง, ปุ่ม) |

| ระดับ | ขนาด | น้ำหนัก | line-height | หมายเหตุ |
|-------|------|---------|-------------|----------|
| H1 หัวเรื่องหน้า | 40px / 2.5rem | 400 | 1.2 | ใหญ่ เบา เห็นชัดในภาพ (ประมาณ) บนมือถือลดเป็น 28px |
| H2 หัวการ์ด | 20px / 1.25rem | 500 | 1.3 | เช่น "Bachelor's Degree" (ประมาณ) |
| Body | 16px / 1rem | 400 | 1.5 | ข้อความในตารางและฟอร์ม (ประมาณ) |
| Label/เมนู | 16px | 500 | 1.4 | เมนูข้าง |
| Caption | 13px / 0.8125rem | 400 | 1.4 | footer, หมายเหตุ (ประมาณ) |
| หัวตาราง | 16px | 600 | 1.3 | ตัวขาว กึ่งกลาง |

ข้อควรระวัง: ภาษาไทยมีสระ/วรรณยุกต์ซ้อนบน ต้องใช้ line-height อย่างน้อย 1.5 กับข้อความย่อหน้า

## 4. ระยะห่างและมุมโค้ง
ใช้หน่วย 4px เป็นฐาน (เสนอ) ค่าจากภาพเป็นค่าประมาณ

| Token | ค่า | ใช้กับ |
|-------|-----|--------|
| `--space-1` | 4px | ช่องไอคอน-ข้อความ |
| `--space-2` | 8px | ระหว่างองค์ประกอบเล็ก |
| `--space-3` | 12px | padding เซลล์ตาราง (แนวตั้ง) |
| `--space-4` | 16px | padding เซลล์ตาราง (แนวนอน), ช่องว่างในการ์ด |
| `--space-6` | 24px | ระหว่างการ์ด, padding หน้า |
| `--space-8` | 32px | ระหว่างหัวหน้ากับเนื้อหา |

| Token | ค่า | ใช้กับ |
|-------|-----|--------|
| `--radius-card` | 4px | การ์ด, ตาราง, ช่องกรอก (มุมโค้งน้อย) (ประมาณ) |
| `--radius-pill` | 999px | ปุ่มหลัก (ปุ่ม SEARCH ในภาพโค้งเต็ม) |
| `--radius-round` | 50% | วงกลมไอคอนเมนู, ตัวเลขหน้า pagination, รูปโปรไฟล์ |

## 5. โครงหน้า (Layout)
| ส่วน | ค่า |
|------|-----|
| แถบหัว (header) | สูง ~76px (ประมาณ) พื้นขาว มีเส้นใต้บางๆ |
| เมนูข้าง (sidebar) | กว้าง ~255px (ประมาณ) พื้นขาว มี scrollbar แคบเมื่อเมนูยาว |
| พื้นที่เนื้อหา | ชิดเมนูข้าง padding ~24px พื้น `--color-bg-page` |
| การ์ด | พื้นขาว เงาบาง `--radius-card` เนื้อหาตารางชิดขอบการ์ด |
| Footer | ข้อความกลาง สีจาง caption เช่นสถิติผู้เข้าชม (ถ้ามี) |
| จุดตัด responsive (เสนอ) | ≥1024px เมนูข้างแสดงเต็ม; <1024px ยุบเป็น drawer เปิดด้วยปุ่ม ☰ |

## 6. แถบหัว (Header)
- ซ้าย: โลโก้และชื่อระบบของ Grade Runway (ต้องออกแบบเอง ห้ามใช้ตราของมหาวิทยาลัย)
- ขวา เรียงจากซ้ายไปขวา: ไอคอนข้อความ/แจ้งเตือน (ซองจดหมาย) → ตัวสลับภาษา `EN | TH` (ภาษาที่ใช้งานอยู่ขีดเน้นหรือสี brand) → รูปโปรไฟล์วงกลม ~36px + รหัส (สี brand) + ชื่อ (สีข้อความ) + ลูกศรเมนูเล็ก
- ไอคอนแจ้งเตือนมี badge จำนวนที่ยังไม่อ่าน (เสนอ) เพื่อรองรับ FR-04

## 7. เมนูข้าง (Sidebar)
| องค์ประกอบ | รูปแบบ |
|------------|--------|
| รายการเมนูระดับ 1 | ไอคอนเส้น 24px + ป้ายข้อความ 16px/500; ระยะแนวตั้ง ~12px |
| กลุ่มที่ขยายได้ | หัวกลุ่มมีลูกศร `⌃/⌄` ชิดขวา; รายการลูกเยื้องเข้า ~12px |
| สถานะ active | ไอคอนอยู่ในวงกลมพื้น `--color-brand-tint` และข้อความเป็นสี `--color-brand` |
| hover | พื้น `--color-bg-page` |
| โฟกัสคีย์บอร์ด | เส้นขอบ 2px `--color-brand` (เสนอ) |

เมนูของ Grade Runway ให้จัดตามบทบาท (ผู้เรียน / ครู-อาจารย์ที่ปรึกษา / ผู้ตรวจ-admin) ตาม [[user-journey]] โดยเมนูที่ผู้ใช้ไม่มีสิทธิ์ไม่ต้องแสดง (NFR-01)

## 8. คอมโพเนนต์

### 8.1 ตาราง
- หัวตาราง: พื้น `--color-brand` ตัวขาว 600 จัดกึ่งกลาง สูง ~40px
- แถวข้อมูล: สูง ~41px พื้น `--color-bg-row-stripe` เส้นแบ่งบาง `--color-border` ข้อความซ้าย ตัวเลข/วันที่จัดกึ่งกลาง
- คอลัมน์เรียงลำดับได้แสดงไอคอน `⇅` ข้างชื่อคอลัมน์ (เช่น "Date")
- ตารางอยู่ในการ์ดขาว หัวการ์ดมีชื่อกลุ่มและลูกศรพับ/ขยายชิดขวา
- มือถือ: ตารางกว้างให้เลื่อนแนวนอนในกรอบ หรือแปลงเป็นการ์ดต่อแถว (เสนอ)
- Pagination: ส่วนบนซ้ายเลือก "จำนวนต่อหน้า" (select); ขวาแสดง "1-3 of 3" + `« ‹ [1] › »` หน้าปัจจุบันเป็นวงกลมสี brand ตัวขาว ~30px

### 8.2 ปุ่ม
| ชนิด | พื้น | ข้อความ | รูปทรง | ขนาด |
|------|------|---------|--------|------|
| หลัก (Primary) | `--color-brand` (ภาพมีไล่เฉดเล็กน้อย ใช้สีเรียบพอ) | ขาว 600 ตัวพิมพ์ใหญ่ | pill | สูง ~38px, padding 24px |
| รอง (Secondary) | ขาว | `--color-brand` | pill, ขอบ 1px brand | เท่ากัน |
| อันตราย (Danger) (เสนอ) | `--status-danger` | ขาว | pill | ใช้กับ "ปฏิเสธ" ที่ต้องมีเหตุผล (FR-15) |
| ปิดใช้ (Disabled) | `#D9D9DE` | `#8A8A94` | เหมือนเดิม | ไม่รับ hover |
- hover: ใช้ `--color-brand-dark`; focus: วงแหวน 2px offset 2px สี brand

### 8.3 ฟอร์ม
- ช่องกรอก/select/วันที่: พื้นขาว ขอบ 1px `--color-border` `--radius-card` สูง ~38px padding ซ้าย 12px (ประมาณ)
- select มีลูกศรลงสี brand ชิดขวา; ช่องวันที่มีไอคอนปฏิทินชิดขวา (ช่วงวันที่แสดงรูปแบบ `01 Oct 2026 - 16 Oct 2026`)
- ชุดตัวกรองอยู่ในการ์ดขาว แถวเดียว ปุ่ม SEARCH ชิดขวาสุด
- โฟกัส: ขอบ 2px `--color-brand`; error: ขอบและข้อความ `--status-danger` พร้อมข้อความอธิบายใต้ช่อง ไม่ใช้สีอย่างเดียว

### 8.4 Badge / ป้ายสถานะ
ต้นแบบไม่มี badge เสนอตามนี้ (เสนอ):
- รูปทรง: pill สูง 24px, padding 0 10px, ตัวอักษร 13px/600
- ประกอบด้วย **ไอคอน + ข้อความ** เสมอ ใช้พื้น/ขอบ/ข้อความตามตารางข้อ 2.4

| ระดับ | ไอคอน | ข้อความ TH / EN |
|-------|--------|-----------------|
| ปกติ | ✓ วงกลม | ปกติ / Normal |
| เตือน | ▲ สามเหลี่ยม | เฝ้าระวัง / Warning |
| อันตราย | ⬣/■ หรือ ! ในรูปแปดเหลี่ยม | เสี่ยงสูง / At risk |
| ข้อมูล | ⓘ | ข้อมูลไม่ทันสมัย / Data outdated |

### 8.5 การ์ดแจ้งเตือน/Alert banner (เสนอ)
แถบเต็มความกว้างการ์ด เส้นซ้ายหนา 4px สีขอบสถานะ พื้นสีจางของสถานะ ไอคอน + หัวข้อ + คำอธิบาย + ปุ่มปิด รองรับ NFR-02 (บอกเหตุผลของการแจ้งเตือน)

## 9. การเข้าถึง (Accessibility)
- สถานะความเสี่ยงต้องมี **ไอคอนและข้อความ** ควบคู่สีเสมอ เพราะแดง-ดิน (brand) กับแดงอันตรายใกล้กัน และเพื่อผู้มีภาวะตาบอดสี
- ตัวอักษรเนื้อหาไม่ต่ำกว่า 16px; พื้นที่กดได้บนมือถือไม่ต่ำกว่า 44×44px
- ทุกองค์ประกอบโต้ตอบต้องมีสถานะ focus ที่มองเห็นและใช้คีย์บอร์ดได้
- ตัวสลับภาษาต้องมี `lang` ที่ถูกต้อง (`th`/`en`) เพื่อให้โปรแกรมอ่านหน้าจอออกเสียงถูก
- ตรวจ contrast ของทุกคู่สีด้วยเครื่องมือจริงก่อนใช้ใน prototype (ตอนนี้คำนวณแค่ขาวบน brand)

## 10. ภาษา (TH/EN)
- ข้อความ UI ทุกชุดต้องมีทั้งสองภาษา; ค่าเริ่มต้นเป็นไทย (เสนอ)
- รูปแบบวันที่: `DD Mon YYYY` เหมือนต้นแบบ (เช่น `16 Oct 2026`) ในภาษาไทยใช้ปี พ.ศ. หรือไม่ ยังไม่กำหนด ดูข้อ 12
