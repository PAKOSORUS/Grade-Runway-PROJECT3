## 1. Sequence Flow

```mermaid
sequenceDiagram
    actor SD as นักศึกษาผู้ส่ง
    actor RC as นักศึกษาผู้รับ
    actor RV as อาจารย์/Admin
    participant AC as Access Control
    participant PC as Peer Chat Manager
    participant RM as Review Manager
    participant DS as Primary Data Store

    SD->>PC: OP-15 ส่งข้อความ (ดูฟีเจอร์ 10)
    PC->>DS: ChatMessage สถานะ = รออนุมัติ
    SD->>AC: OP-17 ดูข้อความที่ฉันส่ง (แบ่งหน้าตามกติกากลาง)
    AC->>PC: อนุญาตเฉพาะที่ผู้ส่ง = ตน
    PC-->>SD: ข้อความทุกสถานะของตน (เห็นสถานะ รออนุมัติ)

    RC->>AC: OP-18 อ่านห้องรวม (แบ่งหน้า เรียงตามเวลาอนุมัติล่าสุดก่อน)
    AC->>PC: อนุญาตบทบาทนักศึกษา
    PC->>DS: อ่านเฉพาะสถานะ = อนุมัติแล้ว (จุดอ่านเดียว)
    PC-->>RC: เฉพาะข้อความอนุมัติแล้ว (รออนุมัติและถูกปฏิเสธไม่ปรากฏ)

    RV->>AC: OP-19 ดูคิวรออนุมัติ
    AC->>RM: อนุญาตเฉพาะอาจารย์/Admin
    RM->>DS: อ่านข้อความ รออนุมัติ ที่ไม่มีล็อกใช้ได้ (ล็อกหมดเวลาที่ยังไม่ถูกปลดนับว่าไม่มีล็อก)
    RM-->>RV: รายการ (เห็นผู้ส่งเสมอ)
```

## 3. State Transition

```mermaid
stateDiagram-v2
    [*] --> รออนุมัติ
    รออนุมัติ --> อนุมัติแล้ว: คำตัดสินที่ถือล็อกที่ใช้ได้ (OP-22)
    รออนุมัติ --> ถูกปฏิเสธ: คำตัดสินที่ถือล็อกที่ใช้ได้ (OP-22)
    อนุมัติแล้ว --> [*]
    ถูกปฏิเสธ --> [*]
```

อนุมัติแล้ว/ถูกปฏิเสธ เป็นสถานะปลายทาง ย้อนไม่ได้ ผู้รับเห็นได้เฉพาะ อนุมัติแล้ว

| สถานะ | ผู้ส่ง (OP-17) | ผู้รับ (OP-18) | ผู้ตรวจ (OP-19) |
|-------|----------------|-----------------|------------------|
| รออนุมัติ (ไม่มีล็อกใช้ได้) | เห็น | ไม่เห็น | เห็นในคิว |
| รออนุมัติ (มีล็อกใช้ได้) | เห็น | ไม่เห็น | ไม่อยู่ในคิว (ดูผ่าน OP-23) |
| อนุมัติแล้ว | เห็น | เห็น | ไม่อยู่ในคิว |
| ถูกปฏิเสธ | เห็นพร้อมเหตุผล | ไม่เห็น | ไม่อยู่ในคิว |

## 4. Edge Case

| กรณี | วิธีจัดการ | อ้างอิง |
|------|-------------|---------|
| นักศึกษาขอรหัสข้อความที่ไม่อนุมัติของผู้อื่น | ERR-NOT-FOUND เหมือนไม่มี | กติกากลาง, NFR-04 |
| เส้นทางอ่านอื่นนอกจาก OP-18 | ต้องไม่มี การกรองสถานะทำที่จุดเดียวใน Backend | Architecture หัวข้อ 6 ประเด็น 2 |
| ล็อกหมดอายุแต่ตัวปลดอัตโนมัติยังไม่ทำงาน | ถือว่าไม่มีล็อก ข้อความแสดงในคิว | OP-19 กฎ |
| ผู้เรียกไม่ใช่อาจารย์/Admin ขอคิว | ERR-FORBIDDEN | OP-19 |
| ข้อความถูกปลดล็อกด้วยมือ/หมดเวลา | กลับเข้าคิว สถานะคงรออนุมัติ ไม่ปรากฏต่อผู้รับ | FR-21, NFR-04 |
| คำตัดสินถูกปฏิเสธเพราะไม่ถือล็อก | สถานะไม่เปลี่ยน ไม่หลุดเป็นอนุมัติ | FR-24 |
